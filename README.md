# KYUMEN App V1

Loja responsiva com catálogo, pesquisa, filtros, carrinho, checkout por WhatsApp, PWA e painel de produtos local.

## Antes de publicar
No `app.js`, altere `WHATSAPP` para o número oficial da KYUMEN e `ADMIN_PASSWORD` para uma palavra-passe sua.

## Atenção
O painel Admin desta V1 usa localStorage do navegador. Não é uma solução segura de produção nem sincroniza entre dispositivos. Para a loja real, a próxima etapa deve ligar autenticação + base de dados + armazenamento de imagens + pagamentos.
